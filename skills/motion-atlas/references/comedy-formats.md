# Comedy formats

Use the Storytelling → Comedy formats folders to study joke construction. Keep them separate from Styles → Comedy editing styles, which concerns framing, visual reveals, cuts, typography, and timing in the edit.

Dad jokes often use corny wordplay and an earnest delivery. Literal jokes make the wording physically or semantically literal. Puns exploit alternate sounds or meanings. A joke can belong to multiple families: tag or cross-reference it rather than forcing an exclusive classification.

When given a reference, record the setup, expected interpretation, pivot, punchline, delivery, and audience context. Explain which detail causes the joke to work. For a video, pair spoken lines with the visible action and the exact reveal moment. For a comment, read the parent thread before adapting the joke.

The catalog contains collection prompts, not a collection of verified successful jokes. Use actual uploaded examples when available; do not pretend a listed template is an analyzed reference. Draft original examples when asked. Choose the family that fits the topic and audience, and preserve a joke’s brevity and intended tone.
